# Load test, 6 October 2026

The same 2,000 requests as [1 October](loadtest-2026-10-01.md) (seed 7), run again after three changes to matching:

1. **Number check:** a cached answer is reused only if its question has the same numbers.
2. **Number words:** "fifteen" and "lima belas" count as 15.
3. **Question cleaning:** the question was lower-cased and stripped of polite openers before it was embedded.

**Result: no wrong answers (6 before), but 24 fewer hits. The cleaning step caused 22 of them, so it was removed.**

**How it was run**

```sh
uv run python -m loadtest.run --requests 2000 --clear-cache --rps 1.5 --llm-rpm 12 --llm-calls-per-miss 1 --llm-budget 440
```

Answers `gemini-3.5-flash-lite`, embeddings `gemini-embedding-001` (768 dimensions), default thresholds for the whole run (nothing was labelled while it ran).

## Where the 24 hits went

The workload is identical, so the runs can be compared request by request. 26 requests that hit on 1 October missed on 6 October, and 2 did the reverse.

| Requests | What happened |
|---|---|
| 21 capital, 1 concept | **Cleaning lowered the similarity below the threshold.** |
| 1 sentiment | A wrong answer on 1 October, now correctly a miss. |
| 3 weather missed, 2 weather hit | Timing (weather answers expire after 5 minutes), and on 1 October the weather threshold was lowered by labels during the run. |

**Why cleaning hurt.** It removed "tell me" as a polite opener. That is right for "Tell me, what is the capital of Spain?", but "Tell me the capital of Spain." became "the capital of spain", which is no longer a question. Against "What is the capital of Spain?" it scores lower than the original sentence did:

| Pair | 1 October (as asked) | 6 October (cleaned) |
|---|---|---|
| "Tell me the capital of X." and "What is the capital of X?", 20 countries, average | 0.970 | 0.939 |
| "Explain the Doppler effect briefly." and "What is the Doppler effect?" | 0.966 | 0.946 |

The factual threshold is 0.95, so all of these went from hits to misses.

Cleaning didn't pay for itself elsewhere either. Of the 214 question pairs that matched in both runs, similarity went down for 127, up for 64, and stayed the same for 23 (average change −0.002). Lower-casing names is one likely reason: "Jane Eyre was written by whom?" against "Which author wrote Jane Eyre?" fell from 0.985 to 0.970. The workload has no pairs that differ only in capitals or a greeting, which is where cleaning could have helped, so that side is unmeasured.

**Decision:** the question is embedded exactly as asked again. The number check and number words stay.

## Wrong answers: 6 to 0

All 6 wrong answers on 1 October were one pair of product reviews, matched at 0.90–0.91 (the classification threshold is 0.90):

* asked: *"Is this review positive or negative? 'The battery died after two days and support never replied.'"*
* served from: *"Is this review positive or negative? 'It stopped working within a week.'"*

With the number check that match can't happen: one review contains the number two and the other contains none.

This is narrower than it looks. Two different reviews with no numbers in them, scoring 0.90 or more, would still share an answer. Classification keeps the lowest threshold of the four question types, so it remains the likeliest place for a wrong answer.

## Not yet measured

The run with cleaning removed. Embeddings of the same text don't change, so it should return to the 1 October similarities: about 86.7% hits with no wrong answers. That is a prediction until the test is run again.
